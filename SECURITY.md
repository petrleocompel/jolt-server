# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub:
**[Report a vulnerability](https://github.com/petrleocompel/jolt-server/security/advisories/new)**
(the "Security" tab → "Report a vulnerability").

Do not open a public issue for anything that could put someone's instance or
account at risk. Include what you found, how to reproduce it, and what an
attacker gains. You will get an answer as soon as the maintainer can look at
it, and credit in the advisory unless you prefer otherwise.

## Supported versions

Fixes land on `main` and in the next release. Run the latest release (the
`latest` image tag); older releases are not patched.

## Scope

In scope: this server, its API, the web dashboard and the published container
image. The iOS app is maintained separately; report issues with it the same
way and they will be passed on.
